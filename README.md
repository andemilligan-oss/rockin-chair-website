# Rockin’ Chair – Offizielle Website

Dies ist das Repository der offiziellen Website von **Rockin’ Chair**, einer Liveband aus Dresden.

## Die Band

Rockin’ Chair spielt handgemachte Livemusik zwischen Rock, Blues und Rock ’n’ Roll. Im Mittelpunkt stehen Spielfreude, echte Instrumente und ein abwechslungsreiches Programm mit Klassikern und weniger erwartbaren Songs.

## Website

Die Website ist vollständig **deutschsprachig**. Sie umfasst:

- Startseite mit dem Motiv des brennenden Schaukelstuhls
- Informationen zur Band
- Musik und Repertoire
- Konzerttermine
- Kontakt und Buchungsanfragen

## Gestaltung

Das Bandmotiv – ein Schaukelstuhl vor einem lodernden Feuer – gibt die Richtung vor: Schwarz, tiefes Rot, Orange, warmes Weiß, markante Typografie und ein authentischer, ungekünstelter Auftritt.

**Bandmotiv:** Die Originalgrafik liegt derzeit im Hauptverzeichnis als `Screenshot_2026-11-15-20-19-23-424_com.google.android.apps.photos-edit.jpg` und ist in `styles.css` eingebunden.

## Technische Umsetzung

Die Seite verwendet HTML, CSS und etwas JavaScript, ohne Build-Prozess. Einstiegspunkt: `index.html`.

### Lokal ansehen

`index.html` im Browser öffnen.

### Über GitHub Pages veröffentlichen

In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

Die Seite wird daraufhin über GitHub Pages veröffentlicht. Eine eigene Domain kann später ergänzt werden.

## Inhalte pflegen

- Konzerttermine: `index.html`, Abschnitt `#termine`
- Bandtexte und Musik: `index.html`
